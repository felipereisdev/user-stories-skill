## Context Summary

Node.js/Express project with TypeScript. Current stack includes PostgreSQL via Prisma ORM. Structure follows MVC pattern with controllers in `/src/controllers`, models in `/src/models`, and middlewares in `/src/middlewares`. Database configuration exists in `/src/config/database.ts`. Project uses `bcryptjs` for password hashing (already installed). Tests run with Jest via `npm test`. A base validator exists at `src/validators/base.validator.ts`, which new validators extend.

## Assumptions

- Registration and login use email and password only; social login is out of scope — the goal names login and registration, and no OAuth library is installed.
- Tokens are stateless JWTs signed with `JWT_SECRET`; refresh tokens are left for a later iteration — matches Feature 3.
- Passwords are hashed with `bcryptjs`, already installed in the project.

## Open Questions

- Should tokens be revocable on logout (a token denylist)? — affects Feature 5 (authentication middleware); assumed for now: no, tokens simply expire.
